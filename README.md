# Ecommerce Website Clone

## Project Overview

This project is a basic ecommerce website clone developed using HTML and CSS. The website mimics the structure and layout of a typical online store, offering a clean, responsive design. It includes essential features such as a homepage, product listing page, and product details, making it a great starting point for building more complex ecommerce websites.

## Features

- **Responsive Design**: The website is fully responsive, adapting to different screen sizes and devices.
- **Homepage Layout**: A welcoming homepage with featured products, banners, and navigation links.
- **Product Listing**: A grid of products with images, titles, and pricing.
- **Product Details Page**: Each product has a dedicated page that displays more detailed information.
- **Navigation Bar**: A functional and simple navigation bar for easy access to different sections of the website.
  
## Technologies Used

- **HTML**: For structuring the web pages and content.
- **CSS**: For styling and layout design to ensure responsiveness and visual appeal.
